# Report format

```
Errors (2)
- Gradient in body background. Fix: flat base color. (/palette)
- "Learn more" button label. Fix: "See our walls". (/copy)

Warnings (1)
- Every grid uses 3 columns. Consider a different layout for "How it works". (/edit layout)

Passes
- No blue-violet hues, contrast 14.4:1, spacing on scale, one accent.
```

Rules: one line per item; name the fixing command in parentheses; keep passes to one line; no praise or filler. After the report, ask the single fix question.
