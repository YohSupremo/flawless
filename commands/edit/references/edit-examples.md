# Edit examples

**Clean change.** `/edit make the headline shorter`. Category: copy. Call `/copy` for the headline only, offer three options under 8 words, apply the pick. Audit clean. Reply: "Headline is now 'Fresh roasted, shipped weekly.' Nothing else changed."

**Rule-breaking change.** `/edit make the background a purple gradient`. Category: colors. Fails two checks (gradient, blue-violet). Ask: "Keep the scheme with a compliant version (same sand base, flat warm panel behind the hero), or use the purple gradient as asked?" Follow the answer.

**Bare `/edit`.** Show scheme: sand base, terracotta accent, Anton and DM Sans, 6px radius, audit clean. Ask which categories. User picks Components. Ask which part, current value first. User picks radius. Apply `--radius` only.

**Pre-existing violations.** Page already has a `/` in a label. User asked for a new button color. Apply the button color; then one line: "The audit also found a '/' in the footer label; want me to fix it?"
