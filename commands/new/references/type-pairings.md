# Type pairings

Choose type for the subject's character. Both from Google Fonts, each with a real fallback stack. One display, one body.

| Character | Display | Body | Suits |
|---|---|---|---|
| Rugged, mechanical | Bebas Neue or Barlow Condensed | Barlow | motorcycles, gyms, tools |
| Heavy, poster-like | Anton | DM Sans | coffee, food, events |
| Editorial, calm | Fraunces or Playfair Display | Inter | studios, publishing, boutiques |
| Clean, technical | Space Grotesk | Inter | software, hardware, services |
| Warm, friendly | DM Serif Display | DM Sans | cafes, clinics, local shops |

Rules: headline line-height 0.95 to 1.05 for condensed faces, up to 1.15 for serifs; no more than two weights per family; never a decorative script for body text.
