# Section patterns (for /section and multi-section builds)

Each section has one job, one h2, and the content itself. No intro paragraph under the heading that restates it. Backgrounds alternate between base and surface, both flat. Section padding is 96 on desktop, 48 on mobile.

## Variety rule

No two consecutive sections share a layout. Three equal cards in a row is allowed once per page, and only when the content is a true set of three. Choose from the patterns below.

| Section | Layout | Content per item | When to use |
|---|---|---|---|
| Products or services | Alternating rows: image or illustration left, text right, then swap | Name, one sentence, one link | 2 to 4 items that each deserve space |
| Product set | Three equal cards | Name, one sentence | Exactly three comparable items |
| How it works | Numbered steps in a single row or column, large numerals in the display font | Step title, one sentence | 3 steps at most |
| Pricing | Simple table with 2 or 3 columns, accent only on the recommended plan's button | Plan, price, 3 to 5 inclusions | Only with real prices from the user |
| Gallery | Asymmetric grid, one large item and smaller ones | Image only, no captions | The user supplies real images |
| FAQ | `details` and `summary` list, one column | Question and 1 to 3 sentence answer | 4 to 6 real questions |
| Location | Two columns: address and hours on the left, a flat map placeholder or embedded map on the right | Address, hours, phone | Only with real details from the user |
| Contact | One column form, three fields maximum, one button | Name, email, message | When the user wants inquiries |
| Testimonials | One large quote at a time, or two columns | Quote, name | Only real quotes the user supplies |

## Never add

Stat strips, "trusted by" logo rows, feature grids with six icon tiles, newsletter sign-up bars the user did not ask for, scroll indicators, floating cards, "why choose us" blocks, or a final call-to-action banner that repeats the hero.

## Footer

Brand name, the links that exist, and nothing else. No tagline, no copyright flourish beyond the year and name.
